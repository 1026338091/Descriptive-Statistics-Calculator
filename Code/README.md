##introduction
There are program for assignment 2. Reads the specified file and calculates descriptive statistics for the specified column. The program can handle floating-point numbers, integers, and skip non-numeric data that cannot be converted.

##method of use
1. Open the terminal and go to the directory where the code is stored. 
2. Run the following command:
python3 stats_in_python.py <filename> <column_number>

Total data：
Number of valid values, Average,Maximum , Minimum, value, Variance , Standard deviation (Std Dev), Median
